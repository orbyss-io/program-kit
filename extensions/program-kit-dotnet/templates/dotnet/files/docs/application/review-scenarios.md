# Review scenarios

Consumer-owned authoring input. For each delivered capability record the audience/role, prerequisites,
input/actions, observable expected outcome and relevant failure cases. Link its actual interface and
executable acceptance test. Explain important semantics that an interface schema cannot show.

Use safe sample data without credentials. Exercise scenarios with ordinary tools; do not claim
behavior from a planned specification, mock API response or historical agent log. Documentation
receivers choose their own publishing workflow.
