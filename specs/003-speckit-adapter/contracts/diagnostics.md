## Adapter result rules

- Adapter diagnostics supplement but never replace Program Kit diagnostics.
- When Program Kit returns valid JSON, `programKitResult` contains those exact
  parsed bytes re-emitted only as the original canonical document; adapter prose
  is not authoritative for factory behavior.
- A malformed child document produces PKSKA0010 and does not fabricate a Program
  Kit result.
- Outcome/effect/disposition aggregate from the furthest proven stage and the
  strictest active diagnostic; no partial success is invented.
- A minimal independent fallback returns `faulted`, the last proven stage/effect,
  PKSKA0010 or PKSKA0012 as applicable, and no unsafe external data.

## Disclosure rules

The following are always withheld from ordinary output:

- credentials and secret-shaped tokens;
- secret-derived fingerprints;
- protected absolute paths;
- raw stdout/stderr from external tools until schema-classified;
- exception messages/objects and stack traces;
- shell command strings or handoff-derived executable prose; and
- unsafe remediation instructions.

Visible paths are normalized workspace-relative logical paths. Visible values
are bounded and typed. Unknown data fails closed to withheld.

## Required executable negative groups

1. **Bootstrap**: repeated exact init, conflicting/drifted state, unsafe/colliding
   path, global shadow, attempted hook init, forbidden effect.
2. **Catalog/restore**: remote/network attempt, one-item implicit selection,
   ranges, duplicate aliases, stale lock, changed distribution, unavailable
   evidence, zero-profile factory mode.
3. **Applicability/defaults**: off/assist/required, unresolved required,
   disabled/non-factory, incompatible inherited selection, changed default,
   attempted silent rebind.
4. **Handoff/trace**: missing/unknown field, conflicting source, unreviewed/stale
   review, edited named source block, unrelated prose edit, changed custom bytes.
5. **Provider/compatibility**: unsupported exact releases/contracts/profile,
   attempted downloaded provider load, private/internal dependency.
6. **Authority**: zero/multiple/stale/revoked/wrong-subject/wrong-effect/widened
   grants, mismatched proposal/decision, invalid finite validity, hook construct.
7. **Filesystem/ownership**: workspace/reparse escape, duplicate/case collision,
   drifted generated bytes, interrupted publication, cleanup against differently
   owned/unproven files.
8. **Process/disclosure**: opaque CLI tokens, secret/exception-derived values,
   malformed/prose-contaminated child output, timeout/cancellation, raw stderr,
   shell-shaped input, telemetry/network/source-upload attempt.
9. **Lifecycle**: incompatible/interrupted update, disable/re-enable with stale
   state, remove with drifted extension file, manifest-aware Spec Kit upgrade.

Every case asserts exact outcome, furthest stage, effect, disposition, diagnostic
identity, safe expected/observed data, evidence, and absence of unauthorized
writes/process/network effects.
