# A shared shopping list for our household

My partner and I often remember things we need at different times. We put notes on
paper or send messages, then whoever goes shopping has to piece the list together.
Sometimes we both buy the same thing, or one of us cannot tell whether an item has
already been bought.

I would like one shared shopping list that we can both understand and keep up to
date. It should help us remember what we need, use the list while shopping, and
see what still needs buying. Later, it would be useful to make regularly bought
items easier to add again and to look back at previous shopping.

Please help me work out a small first version that would already be useful to us,
and how the other improvements could follow. I have not decided the screens,
detailed rules, or technical design.
