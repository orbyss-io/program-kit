# Internal Forms feature exercise

Use the accepted Internal Forms Workspace architecture and existing selected building blocks.
Deliver RM01: an internal operator can open a form, enter a title and description, submit a valid
request, and see the saved request after a reload. Invalid input must show an accessible field
error and must not create a record. Keep the accepted BFF session and API boundary. Exercise
the accepted Forms React package from its declared registry, as well as public npm dependencies
and the selected .NET packages. Use the exact approved tooling and strict dependency checks.

RM02 is a later reporting feature. It may remain in the roadmap and placement inventory, but its
application files must not be scaffolded or materialized by RM01 setup or by an upgrade.

Work through the installed Spec Kit commands and hooks. Start with feature grilling and stop for
the human to review the synthesized brief. A fixture is not the human's confirmation. After the
human confirms that exact brief, proceed through specify, clarify, plan, tasks, implementation
setup and implementation. Preserve evidence for every gate. Independent verification must check
the behavior above and both selected ecosystems; a worker's final statement is not acceptance.

The paid worker may ask the supervisor for dependency metadata, strict graph resolution and
restore through the shipped mechanism. The supervisor owns package network access and registry
credentials. Stop at each required package boundary; do not invent evidence or bypass a gate.
Each new paid worker session needs its own exact, one-use authorization.

For the upgrade case, begin with the verified baseline consumer and additional consumer-owned
source and configuration edits. Run the shipped offline upgrade, follow its readiness report,
refresh only stale dependency evidence through the supervisor, and resume the feature flow.
Verify the original behavior and consumer edits after upgrade. Repeat the unchanged sync and
upgrade checks, preserving command and operation evidence.
