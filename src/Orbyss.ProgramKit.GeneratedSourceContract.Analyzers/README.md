# Orbyss.ProgramKit.GeneratedSourceContract.Analyzers

This analyzer-only package implements exactly one public Program Kit contract:
`pkid:contract:program-kit:generated-source-convention@1.0.0`.

`PKCC001` checks the compilation-observable pairing between the exact
`// <auto-generated program-kit>` first-line header and the exact
`ProgramKitGenerated/<intent>/<file>.cs` logical path. It does not prove
generator identity, ownership transfer, manifest selection, physical-source
inventory, or any Program Kit-private `PKCS` policy.

Selection is direct and opt-in:

```xml
<PropertyGroup>
  <ProgramKitGeneratedSourceContract>1.0.0</ProgramKitGeneratedSourceContract>
  <ProgramKitPublicAnalyzerReceiptNonce>0123456789abcdef0123456789abcdef</ProgramKitPublicAnalyzerReceiptNonce>
</PropertyGroup>
<ItemGroup>
  <CompilerVisibleProperty Include="ProgramKitGeneratedSourceContract" />
  <CompilerVisibleProperty Include="ProgramKitPublicAnalyzerReceiptNonce" />
  <PackageReference
    Include="Orbyss.ProgramKit.GeneratedSourceContract.Analyzers"
    PrivateAssets="all"
    IncludeAssets="runtime; build; native; contentfiles; analyzers; buildtransitive" />
</ItemGroup>
```

The package contains only `analyzers/dotnet/cs` plus its contract, schema, and
README. It contains no `lib`, `ref`, `runtime`, `build`, or `buildTransitive`
asset and activates no unrelated Program Kit rule.
