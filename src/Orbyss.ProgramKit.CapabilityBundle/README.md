# Orbyss.ProgramKit.CapabilityBundle

This content-only package carries exact copies of the three distributable
Program Kit development capabilities:

- `develop-software`
- `design-software`
- `implement-software-plan`

Their thin Codex wrappers are separately listed optional provider adapters. The
repository-only `publish-dotnet-application-locally` capability, the capability
index, generated catalog, authoring capability, and Release Cycle reservations
are deliberately excluded.

Installing or copying this package does not register a capability. A human must
explicitly materialize selected canonical definitions, choose provider wrappers,
and update the consumer repository's own capability availability authority.
