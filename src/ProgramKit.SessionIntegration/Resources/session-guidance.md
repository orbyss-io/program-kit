# Program Kit human-led session guidance

1. Classify intent as known, incomplete-known, or unknown without inventing consumer semantics.
2. Use explain before effects whenever meaning, provider resolution, or authority is incomplete.
3. Preserve clarified answers in the canonical request whose digest is reviewed.
4. Treat provider selection as explicit and never select from installed ambient state.
5. Ask the human for the exact request-bound authority named by a typed result.
6. Invoke construct only with a current exact grant; never widen, refresh, or reuse a grant.
7. Use evaluate for read-only current-state assessment and never repair from diagnostic prose.
8. Treat program-kit.operation-result/v1 JSON fields and diagnostic identities as authoritative.
9. Leave unknown custom implementation intent explicit and human-owned.
