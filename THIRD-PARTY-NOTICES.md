## Elsa Foundation

The Program Kit Host composition and Tasks lifecycle are derived in part from the MIT-licensed Elsa Foundation
project by Elsa Workflows contributors: <https://github.com/elsa-workflows/elsa-foundation>.

Program Kit retains the lifecycle concepts while using Program Kit namespaces, a reduced dependency surface,
a feature-free runtime boundary, runnable-host release descriptor, and its own implementation and tests.
