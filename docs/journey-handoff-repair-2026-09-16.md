## Repairs

- Accept an exact condition-to-cataloged-ADR binding in the validated source inventory as phase
  assignment authority. Proposed is permitted only during pending review; readiness needs Accepted.
  This leaves the condition open. Closed conditions still need their actual closure evidence;
  a stale source hash, register-only reassignment or unaccepted authority still fails.
- Add optional `supporting_journeys` to canonical candidates, preserving existing single-journey
  models. First-entry projection, exact coverage, future-scope exclusion and accepted/pending map
  scope now inspect every declared journey, including its relationships and endpoints.
- Permit repeated interactions in dynamic journey order. Selected relationship identities remain
  unique; ordered occurrences may repeat. Intake derivation, semantic validation and DSL import/
  export agree. This follows Structurizr's documented ordered instances of relationships:
  https://docs.structurizr.com/dsl/cookbook/dynamic-view/ (checked 2026-09-16).
- Parse constitution metadata anywhere in the document, retaining exactly-one-field, valid date,
  version and governance-policy checks. Valid header metadata was previously rejected because the
  search was restricted to the Governance section.
- When a recorded workflow admitted the intake but the final original-artifact check now fails,
  report `downstream-review-required`, preserve the failed check and admitted run IDs, and explicitly
  leave current-stage validity unestablished. Historical admission never confirms a changed intake.

The first two defects are mismatches between authoring and executable handoff contracts. More
knowledge text alone would not fix them. The latter findings also show how unnecessary formatting
restrictions and ambiguous reporting magnify the cost of ordinary agent variation.
