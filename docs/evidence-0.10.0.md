# Program Kit 0.10.0 release evidence

The source semantic regression uses a fresh disposable pricing consumer with six separately named
journeys, four candidate bounded contexts, classified Core/Supporting/Generic subdomains, owned
modules, typed contracts, seven explicit bridges (including the managed Forms boundary), and
founding decision candidates with alternatives and consequences.

Negative gates cover missing journey traceability, untyped cross-context dependencies, orphan
modules, ungoverned cross-context atomicity, Program Kit Forms absorbing consumer semantics,
unchallenged cross-cutting-concern contexts, premature intake decision acceptance, stale draft
artifacts, malformed JSON/DSL, and legacy 1.0 intake/map rejection.

The clean installed-consumer path performs generation of the 1.1 artifacts, read-only draft C4
inspection, explicit intake confirmation, and final validation in that order. The final bootstrap
gate binds every founding decision candidate to one Proposed ADR, promotes only that reviewed bundle
to Accepted, refreshes canonical ADR hashes and affected map semantics, regenerates the projection,
and leaves unrelated Proposed ADRs unchanged.

Publication requires the complete source, release-package, clean-install, previous-stable upgrade,
and public install/upgrade suites. A real pinned Structurizr container run additionally validates the
generated custom strategic views and journey dynamics without importing viewer state.
